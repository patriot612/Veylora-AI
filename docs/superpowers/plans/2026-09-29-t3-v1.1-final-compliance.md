# T3 v1.1 Final Compliance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close every repository-addressable T3 v1.1 gap identified by the final audit, while preserving the existing Worker/D1/Queue/AI Gateway architecture.

**Architecture:** Keep Cloudflare Worker, D1, Queues/DLQ, AI Gateway, SearXNG and Telegram as currently implemented. Fix T3 behavior at the existing service/UI boundaries; use D1 transactions/ownership predicates for lifecycle operations and durable references for retryable media results.

**Tech Stack:** TypeScript, Cloudflare Workers, D1/SQLite, Queues, Telegram Bot API, Vitest, Wrangler.

**Spec:** T3 v1.1 FINAL SPEC PACKAGE supplied in the project conversation; execution constraints also follow `Qelvion_AI_Implementation_Mechanics_Handoff.docx`.

## Global Constraints

- D1 is SQLite; do not introduce PostgreSQL RLS.
- Queue messages must contain references/metadata, not large binary payloads.
- Billing remains reserve -> execute -> settle, or release on terminal failure.
- Identity, role, price, points and operation state are server-derived.
- Provider credentials remain encrypted and must not be exposed to clients or committed to Git.
- Search content is untrusted input and must not become system instructions.
- Do not add a second backend, billing service, or queue architecture.
- Every changed behavior gets regression coverage and the full verification workflow must remain green.

## Review Focus

- Archived-dialog deletion must be truly permanent and confirmed by the user.
- Locked/insufficient-point Chat paths must expose the exact actionable T3 UX without routing to unrelated menus.
- Daily points shown in Account must reflect the current reset window.
- Image binary results must survive Telegram retry without re-running provider generation.
- Admin health/configuration UX must represent actual operational state rather than only counters.
